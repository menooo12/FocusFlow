# 🎯 FocusFlow - Study Planner & Focus Tracker

##  Overview

**FocusFlow** is a simple and smart study planner that helps students manage their subjects, track study sessions, and analyze their performance.

The system provides intelligent feedback based on study hours and helps users improve their focus and productivity.

---

## Features

* 📚 Add and manage subjects
* ⏱️ Track study sessions
* 📊 Dashboard with statistics
* 🧠 Smart feedback system
* 🎯 Focus Score calculation

---

## Technologies Used

* ASP.NET MVC
* C#
* HTML / CSS
* Bootstrap

---

## How It Works

1. User adds subjects with target study hours
2. User logs study sessions
3. System calculates:

   * Total study hours
   * Focus Score
   * Weak and strong subjects
4. Smart messages are shown to guide the user
